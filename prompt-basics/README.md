# Prompt Basics

This folder contains exercises for learning the basics of LLM prompting, including prompt refinement, few-shot prompting, and generation parameters.

The biggest difference I saw between a vague and a precise prompt is that a precise prompt gives the LLM clearer instructions and constraints, which leads to more predictable and useful results.

I would lower the temperature when I want more consistent and predictable output, such as when generating code or structured answers. and higher it when I want ideas and creativity.
