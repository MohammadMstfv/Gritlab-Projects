## About Gritlab

**Gritlab** is a two-year, project-based software development education program focused on developing practical programming skills, technical knowledge, and the ability to solve real-world problems through hands-on learning.

The program follows an intensive, practice-oriented approach where learning happens primarily through coding, experimentation, independent research, and project development. Instead of relying solely on traditional lectures, students are encouraged to take an active role in their education, explore unfamiliar concepts, learn from mistakes, and develop solutions independently.

Throughout the two years, students progressively build their programming knowledge, work with different technologies, and take on increasingly complex assignments and projects. The learning environment emphasizes not only technical skills but also problem-solving, adaptability, collaboration, and continuous self-improvement.

### Learning Approach

The program encourages students to:

- Develop a strong foundation in programming and software development.
- Learn by building practical projects and solving programming challenges.
- Research, explore, and understand unfamiliar technologies independently.
- Write structured, readable, and maintainable code.
- Approach complex problems through logical thinking and systematic debugging.
- Develop the ability to learn new tools, languages, and technologies.
- Build confidence working both independently and collaboratively.
